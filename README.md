# CakePrice App

CakePrice is a professional cake pricing application created for cake decorators who want to price their work accurately, confidently, and profitably.

It was built by a working cake decorator who understands the real challenges of running a baking business.

---

## 🎯 Purpose

The main purpose of CakePrice is to help decorators:

- Stop underpricing their work
- Understand their real costs
- Create consistent and professional quotes
- Build sustainable and profitable businesses

CakePrice replaces guesswork with real data.

---

## ✨ Key Features

### FREE Version
- Basic and advanced cake calculator
- Manual ingredient cost input
- Client quote preview
- Print and PDF export
- Currency selection
- Local storage (no login required)

### PRO Version
- Save and reuse recipes
- Save and manage quotes
- Tiered cake calculator
- Operational costs (energy, rent, utilities, marketing)
- Brand customization (logo and business name)
- Advanced pricing tools

---

## 🧩 Product Decisions

These decisions were made intentionally:

- No user accounts (MVP focus)
- Data stored locally in browser (LocalStorage)
- One-time payment (no subscription)
- Clear separation between FREE and PRO features
- Focus on usability for non-technical users

---

## 🛠️ Tech Stack

- Framework: Next.js
- Library: React
- Language: TypeScript
- Styling: Tailwind CSS
- Storage: Browser LocalStorage
- Payments: Stripe (one-time payment)

---

## 🗂️ Data Storage

All user data is stored locally in the browser:

- Recipes
- Quotes
- PRO state
- Brand settings

⚠️ Clearing browser data will remove saved information.

Cloud sync is planned for future versions.
